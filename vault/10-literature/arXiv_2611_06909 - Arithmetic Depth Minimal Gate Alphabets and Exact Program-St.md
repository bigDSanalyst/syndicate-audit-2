# Arithmetic Depth, Minimal Gate Alphabets, and Exact Program-State Resources for Single-Qubit Dyadic Programs

## Abstract

> Resource analyses for quantum programs commonly provide safe upper bounds on qubits, gates, or
> non-Clifford operations. We study a single-qubit dyadic fragment in which the deepest exact
> resource layer can instead be inferred exactly. Starting from the normalized-midpoint misty-
> state syntax, we define dyadic program states and the real cyclotomic tower $K_D=\mathbb
> Q(2\cos(π/2^D))$. For the projective single-qubit Clifford-cyclotomic tower $\widehat
> G_D\subseteq SO(3)$, we prove the relative intersection law $\widehat G_D\cap SO(3,K_d)=\widehat
> G_d$ for $d\le D$. Combining this descent theorem with an arithmetic-closure invariant for
> adaptive stabilizer processing yields
> $\mathrm{Fdepth}(U)=\mathrm{Adepth}(U)=\mathrm{Rdepth}(U)$: the smallest real cyclotomic field
> containing the Bloch matrix of an exactly synthesizable channel, the shallowest dyadic gate
> alphabet realizing it up to global phase, and the shallowest dyadic program-state layer
> sufficient for exact stabilizer-assisted implementation coincide. At that common minimum, known
> fixed-alphabet synthesis gives minimum primitive-rotation count. We package the result as an
> exact static resource effect and outline a certificate-producing compiler.
