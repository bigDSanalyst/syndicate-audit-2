# CV-TF-QKD

## Abstract

> We introduce a continuous-variable version of twin-field quantum key distribution, using
> independent Gaussian-modulated coherent states and an untrusted single-photon relay. Full-record
> reconciliation and a binary phase-disclosure protocol achieve nearly equal asymptotic key rates
> against collective attacks. At fixed weak input-referred excess noise per arm, both rates per
> relay use scale as $\sqrtη$, where $η$ is the end-to-end transmissivity. For phase disclosure,
> we establish composable security against general coherent attacks using a bounded test of
> preparation intensities and sign-parity complementarity. For specified apparatus parameters,
> finite-key calculations incorporating detector inefficiency, dark counts, phase fluctuations,
> and reference overhead predict rates exceeding the pure-loss and matched thermal-loss
> repeaterless bounds. These results extend the twin-field advantage to Gaussian-modulated
> continuous-variable quantum cryptography.
