# SwapBot: Tool-Centric Robot Manipulation via Interchangeable End-Effectors and Tactile Sensing

## Abstract

> Robot manipulation in everyday environments inherently involves substantial tool usage.
> Seemingly simple household tasks, such as cooking pan-fried tofu, require forceful cutting,
> delicate brushing, and precise placement using different tools under contact-rich interaction.
> Thus, the ability to autonomously swap and use task-appropriate tools is important for tool-
> centric manipulation. We introduce SwapBot, a modular, tool-centric end effector system
> featuring low-cost adapters that quickly convert common household tools into robot end
> effectors. Rather than pursuing a single universal gripper, SwapBot adopts a unified design
> principle that combines a fixed robot-side coupling interface with low-cost, tool-side adapters,
> enabling compatibility with diverse tools, including articulated ones, and multiple robot
> platforms. Each adapter integrates compact tactile sensors, supports fast autonomous swapping,
> and interfaces with an intuitive teleoperation system for efficient demonstration collection.
> User studies show that, during teleoperation, SwapBot reduces task completion time and operator
> workload. Using collected demonstrations on the robot, we train imitation learning policies to
> successfully perform tool-centric tasks like cooking tofu, stirring salad, flipping meat. Our
> ablation study shows that using tactile-augmented demonstrations improves policy performance
> across contact-rich skills, increasing success rates by 15 to 25 percentage points over RGB-only
> policies. These results highlight modular, tactile-equipped tools as a practical and extensible
> pathway toward robust and capable robot manipulation. Project website
> https://personalrobotics.github.io/SwapBot.
