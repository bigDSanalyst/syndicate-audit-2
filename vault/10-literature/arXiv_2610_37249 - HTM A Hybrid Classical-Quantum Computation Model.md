# HTM: A Hybrid Classical-Quantum Computation Model

## Abstract

> Classical and quantum computers have achieved collaborative computation and completed
> applications across numerous fields. Nevertheless, the absence of a unified hybrid computation
> model has led to issues such as non-standardized engineering architecture design, ambiguous task
> partitioning criteria and so on. To address these issues, this research proposes a hybrid
> classical-quantum computation model (HTM). By constructing unified state sets and transition
> function representations, HTM clarifies hybrid control logic and implements a control-sharing
> mechanism. Simultaneously, a comprehensive complexity calculation method based on entanglement
> and superposition was proposed, supporting computation task partitioning and resource
> scheduling. The HTM fills a theoretical gap in the classical-quantum hybrid computation area and
> implements the joint promotion and development of computing models and hardware.
