# Human Mobility Sensing Using Wall-Reflected Beamformed Millimeter-Wave Communication Signals

## Abstract

> Existing millimeter-wave (mmWave) communication beam patterns spatially weight human-scattered
> signals and shape the received-power signatures induced by human motion. We exploit these beam-
> shaped signatures for device-free walkingpace and walk-direction classification using a wall-
> reflected 60.8-GHz link with closely spaced phased arrays and fixed communication beamforming
> vectors. Human movement alters the interference between wall-reflected and scattered signals,
> producing power oscillations surrounding a central blockage fade. A beam-dependent interference
> model provides a physical interpretation of these signatures. Using received-power statistics
> from a continuous-tone experiment, we extract fade duration for walking-pace classification and
> pre/post-fade asymmetries for walk-direction classification. Measurements comprise 144 crossings
> from three participants along perpendicular and diagonal trajectories. Under leave-one-
> participant-out validation, logistic regression achieves 86.1% binary and 79.2% three-class
> walking pace accuracy, and 77.1% travel-direction accuracy. The results demonstrate mobility
> sensing using fixed communication beams without channel estimation, Doppler processing, or
> dedicated radar hardware
