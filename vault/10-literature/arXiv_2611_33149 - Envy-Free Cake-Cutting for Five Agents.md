# Envy-Free Cake-Cutting for Five Agents

## Abstract

> We study the envy-free cake-cutting problem, in which a divisible resource must be divided among
> a set of agents with heterogeneous preferences in a way that ensures that no agent envies the
> piece obtained by another. Remarkably, under some mild continuity assumptions on the agent
> valuations, it is known that an envy-free division where each agent receives a \emph{connected}
> piece of the cake is always guaranteed to exist. When the valuations are monotone, prior work
> has shown that a connected $\varepsilon$-envy-free division can be obtained using
> $\poly(\log(1/\varepsilon))$ queries for up to four agents, leaving the case of five or more
> agents open. In this work, we develop a new simpler approach that yields such an efficient
> algorithm for five agents. Our algorithm uses $\mathcal{O}(\log^3(1/\varepsilon))$ queries and
> also yields a novel proof of existence for five agents that does not rely on any fixed-point
> theorems beyond the intermediate value theorem.
